# ATRANG 2026–27

The website for **Atrang 2026–27**, the annual technical fest of IIIT Tiruchirappalli — a Minecraft-inspired
world with a live 3D landscape, a game-style main menu, block-breaking interactions, and an explorable events
board.

There is no backend. All content lives in local TypeScript files.

> A Minecraft-inspired fan design. Not affiliated with Mojang Studios or Microsoft. Textures and the logo are
> original and generated by code in this repo. The audio in `public/audio/` was supplied by the team — confirm
> you have the rights to it before publishing the site.

## Quick start

Requires Node.js 20.9 or newer.

```bash
npm install
npm run dev        # http://localhost:3000
```

| Command             | What it does                                       |
| ------------------- | -------------------------------------------------- |
| `npm run dev`       | Start the development server                       |
| `npm run build`     | Production build (both routes prerender as static) |
| `npm run start`     | Serve the production build                         |
| `npm run lint`      | ESLint (Next.js + React Compiler rules)            |
| `npm run typecheck` | TypeScript in strict mode                          |
| `npm run format`    | Prettier                                           |
| `npm run textures`  | Regenerate the pixel textures and favicon          |

## Running with Docker

The repo ships a production `Dockerfile` and a `compose.yaml`. The image runs Next.js's standalone server
(Node 22 on Alpine, ~240 MB) as the non-root `node` user, with a built-in health check.

```bash
cp .env.example .env          # set NEXT_PUBLIC_SITE_URL and ATRANG_PORT for the server
docker compose up -d --build  # build the image and start the container
docker compose ps             # STATUS should read "healthy" after a few seconds
docker compose logs -f        # follow the server log
docker compose down           # stop and remove the container
```

| Setting                | Where                   | Default                 | Notes                                      |
| ---------------------- | ----------------------- | ----------------------- | ------------------------------------------ |
| `NEXT_PUBLIC_SITE_URL` | `.env` (build argument) | `http://localhost:3000` | Baked in at build time — rebuild to change |
| `ATRANG_PORT`          | `.env`                  | `3000`                  | Host port mapped to the container's 3000   |

Without Compose:

```bash
docker build -t atrang --build-arg NEXT_PUBLIC_SITE_URL=https://your-domain .
docker run -d --name atrang -p 3000:3000 --restart unless-stopped atrang
```

Notes for the server:

- **Network during build:** only the npm registry is needed. Fonts are bundled in `src/app/fonts/`, so the
  build never contacts Google Fonts.
- **Hardening:** Compose runs the container with a read-only filesystem, all Linux capabilities dropped, and
  `no-new-privileges`. Next's cache directory and `/tmp` are in-memory `tmpfs` mounts.
- **Reverse proxy:** to serve on port 80/443 behind nginx or Traefik, proxy to the container's port 3000.
  Static assets under `/_next/static/` are sent with `Cache-Control: public, max-age=31536000, immutable`.
- **Updating content:** edit `src/data/events.ts` (or anything else), then `docker compose up -d --build`.

## Stack

- **Next.js 16** (App Router, Turbopack, Cache Components, standalone output) with **React 19** and
  **TypeScript** (strict)
- **Tailwind CSS 4** — design tokens live in `src/app/globals.css` under `@theme`
- **Three.js** via **React Three Fiber** and **Drei** for the 3D world
- **Motion** for modal, grid, and particle animations
- **Lucide** icons
- Audio runs on the Web Audio API with no extra library: sample files where provided, synthesised UI blips
  otherwise

`three` is pinned to `0.182.x`: newer releases deprecate `THREE.Clock`, which the current stable React Three
Fiber (9.x) still uses, and that logs a warning on every page load. Upgrade once R3F 10 is stable.

ESLint is on v10 (v9 is end-of-life). Three plugins bundled by `eslint-config-next` (`import`, `jsx-a11y`,
`react`) haven't widened their declared peer range past v9 yet, so `package.json` has `overrides` pointing them at
the installed ESLint; their rules run normally. Remove the overrides once those plugins declare v10 support.

## Customising content

### Events and biomes — `src/data/events.ts` (the only file you edit)

Everything about events lives in this one file, in two sections. The biome picker, filters, counts, card
colours, particle colours, and page descriptions are all generated from it.

**`BIOMES`** — one entry per category, with its in-world name, accent colour, and icon:

```ts
import { Bot, CodeXml, Laptop } from "lucide-react"; // any icon from https://lucide.dev/icons

export const BIOMES = {
  Coding: { name: "Syntax Peaks", color: "#34c27a", icon: CodeXml },
  Hackathon: { name: "Hackers' Hollow", color: "#a46bff", icon: Laptop },
  Robotics: { name: "Iron Foundry", color: "#b9c2cf", icon: Bot }, // a new category
} satisfies Record<string, Biome>;
```

**`EVENTS`** — the events. Each one names its biome with `category`; events that share a category (for
example two hackathons) are grouped into the same biome automatically:

```ts
{
  id: "crossover",                 // unique, URL-safe, never reused
  title: "Crossover",
  summary: "Shown on the card.",
  description: `Shown in the details panel.
Line breaks are kept.`,
  category: "Hackathon",           // must be a key of BIOMES
  participation: "Team",           // optional: "Individual" | "Team" | "Individual or Team"
  teamSize: "3–4 members",         // optional
  duration: "24 hours",            // optional
  prize: "₹4,000 winner",          // optional
  registrationUrl: "https://…",    // optional — shows a "Register" button; otherwise "coming soon"
  highlights: ["…"],               // optional bullet points
  color: "#ff5a4f",                // optional — override the biome colour for this event only
  icon: Rocket,                    // optional — override the biome icon for this event only
}
```

Missing optional fields display as "To be announced". Biomes with no events are hidden. Mistakes are caught
early: a misspelt `category` is a type error, and a duplicate `id` or a malformed colour stops the page with a
message naming the problem.

### Fest details and copy — `src/lib/constants.ts`

Fest name, edition, college, tagline, navigation items, the rotating splash lines next to the logo, and the
keyboard controls list shown in Settings.

Set `NEXT_PUBLIC_SITE_URL` to the deployed origin so social previews resolve absolute URLs.

### Look and feel

- **Colours, fonts, buttons, panels:** `src/app/globals.css` (`.mc-btn`, `.mc-panel`, `.mc-input`, …)
- **Textures:** edit `scripts/generate-textures.mjs`, then run `npm run textures`
- **Wordmark:** the block glyphs are defined in `src/components/branding/AtrangLogo.tsx`
- **Sky and lighting presets:** `src/lib/world/atmosphere.ts`
- **Terrain shape:** `createHeightField` in `src/lib/world/generate.ts` (seeded, so it is identical on every load)
- **Camera shots per route:** `SHOTS` in `src/components/world/CameraRig.tsx`
- **Quality tiers (terrain size, trees, shadows, pixel ratio):** `QUALITY` in `src/components/world/sceneState.ts`

### Audio — `src/lib/audio-config.ts`

| File                                | Used for                                                      |
| ----------------------------------- | ------------------------------------------------------------- |
| `public/audio/background-music.mp3` | Looping background music (128 kbps, cover art stripped)       |
| `public/audio/block-break.wav`      | One 300 ms block break, played when a block finishes cracking |

The break sound was cut from a longer mining recording (one break, with a 2 ms fade-in and 90 ms fade-out).
Each play is pitch-shifted by up to ±8% so repeated breaks don't sound identical. To swap a sound, drop a new
file in `public/audio/` and update its path in `AUDIO_FILES`; remove an entry to fall back to the synthesised
version. Clicks and panel sounds are synthesised.

## How it fits together

```
src/
  app/                 routes: / (main menu), /events, not-found
  components/
    branding/          AtrangLogo, PixelHeading, SplashText
    minecraft/         MinecraftButton, BreakableBlock, BlockPanel, BlockParticleBurst
    home/              HomeHero, MainMenu, AboutModal
    events/            EventsExperience, EventsHero, EventFilters, EventSearch, EventGrid, EventCard,
                       EventDetailsModal, EmptyEventsState, IsoCube
    layout/            SiteHeader, SiteFooter, PageTransition, AppProviders
    ui/                Modal, SettingsModal, SoundToggle, MusicToggle, LoadingScreen
    world/             WorldBackground, WorldScene, Terrain, BlockTrees, CloudLayer, FloatingBlocks,
                       Fireflies, Sky, CameraRig, SceneFallback, materials
  data/events.ts       BIOMES + EVENTS — the only place event content lives
  hooks/               useBlockBreak, useReducedMotion, useSoundEffects, useEventFilters, useQualityLevel
  lib/                 constants, settings store, sound effects, music, particle bus, filtering, world generation
  types/event.ts       the shape of a biome and an event
```

**One persistent world.** The 3D scene is mounted once in the root layout (`WorldBackground`) and never
remounts. Each route asks the camera for a different shot, so navigating flies the camera from the menu
panorama to an aerial "world map" over the valley. The canvas ignores pointer events, is lazy-loaded on the
client only, and pauses rendering when it is scrolled out of view or motion is reduced.

**Cheap voxels.** The terrain generator emits only blocks that can be seen, grouped by type, and each type is a
single instanced mesh — the whole landscape is roughly a dozen draw calls. Materials and the cube geometry are
shared everywhere.

**Block breaking.** `useBlockBreak` drives the crack stages (~320 ms), then fires a particle burst through a
global layer (so debris keeps flying after navigation) and runs the action. With reduced motion it becomes a
short highlight.

**Settings** (sound effects, music, volume, motion, graphics quality, time of day) persist to `localStorage`.
Sound and music are off by default and only start after a user gesture; music pauses while the tab is hidden.

## Accessibility and fallbacks

- Keyboard: every control is reachable; arrow keys move through the main menu, `/` focuses event search, `M`
  toggles sound effects, `B` toggles music, `Esc` closes panels. Dialogs trap focus and restore it when closed.
- Respects `prefers-reduced-motion`, with an in-app override in Settings.
- Without WebGL, a static CSS/SVG landscape replaces the 3D scene. Without JavaScript, pages still render, links
  work, and the loading screen hides itself.
- Sound is never the only feedback for an interaction.
